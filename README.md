# Bukyho svět

První webová/PWA verze menu hry **Bukyho svět od Ranče na Křivé**.

## Obsah
- klikací menu,
- pohybující se Buky,
- pozdrav „Ahoj kamaráde!“,
- úvodní znělka,
- zpěv ptáků,
- PWA instalace na plochu mobilu.

## GitHub Pages
Repozitář musí mít zapnuté:
- Branch: `main`
- Folder: `/ (root)`

Potom web poběží přes GitHub Pages.
